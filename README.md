# Beth Qudsho – Website

Public website of the Beth Qudsho app (Syriac Orthodox liturgy): start page, privacy policy and support,
in English and German. Plain HTML and CSS, hosted with GitHub Pages – no cookies, no analytics, no external resources.

- Start: `index.html`
- Privacy policy: `privacy/index.html`
- Support: `support/index.html`

The Syriac heading uses SyrCOM Jerusalem (© 2001 Beth Mardutho: The Syriac Institute, for free distribution),
included unmodified in `assets/`.
